CORE HIGHLIGHTS

為認真跑者打造的運動科學工程

不只是搬運數據，而是透過頂尖耐力科學公式與 Google 生成式 AI 模型，將手錶數據轉化為真正具備指導價值的每日訓練決策。

丹尼爾 VDOT 靶心配速

依據 Daniels & Gilbert (1979) 攝氧量阻力公式，依個人全馬 PB 自動反解當前 VDOT 跑力，精確推算 E、M、T、I、R 五大訓練配速區間。

ACWR 28 天體能與受傷預警

回溯近 28 天訓練歷程，計算 7 天急性與 28 天慢性負荷比，精確鎖定 0.8~1.3 體能增長「甜點區 (Sweet Spot)」，杜絕過度訓練。

前後半程有氧解耦率

引進 Joe Friel 效率因子 (EF) 模型，精準將運動切分前後半程，計算心率漂移百分比，四段科學等級檢驗有氧耐力底層。

目標賽事倒數與每日菜單

自動調閱 Garmin 行事曆近三個月目標賽事（智慧去重），判讀基礎期、專項期或減量期 (Taper)，開立每日具體距離與配速菜單。

Gemini 多模型自動降級備援

動態掃描最新 Gemini 2.5 / 2.0 Flash 模型陣列，若遭遇尖峰 503 UNAVAILABLE 錯誤，毫秒級自動容錯降級重試，推播 100% 不中斷。

Open-Meteo 歷史微氣候

以 GPS 軌跡與起跑時間座標精準抓取當下氣溫、濕度與體感溫度，讓 AI 教練將外部熱壓力與脫水風險納入生理綜合考量。

高階跑步動態全解剖

手錶跑步功率 (W)、步頻 (spm)、步幅、垂直振幅、步幅比與觸地時間 (GCT) 全面分析，診斷跑姿經濟性與落地衝擊風險。

HRV 與體能優雅降級

整合夜間 HRV 心率變異度、靜止心率 (RHR) 與身體電量；未配戴手錶入睡時自動優雅略過，絕不中斷主流程。

FREQUENTLY ASKED QUESTIONS

常見問題解答

關於安全性、成本、API 與排程的所有疑問。

真的完全不需要支付任何費用嗎？

是的，100% 免費！GitHub Actions 每月提供 2,000 分鐘的免費 CI/CD 執行時間（本程式每日僅需跑 30~50 秒）；Google Gemini API 亦提供免費額度（每日足夠使用數百次）；Open-Meteo 天氣查詢無需金鑰完全開源免費。

我的 Garmin 帳號密碼安全嗎？

非常安全。所有帳號密碼都是儲存在您個人私有的 GitHub Repository Secrets 中，經由 GitHub 伺服器進行非對稱非對稱加密（Asymmetric Encryption）。程式碼為 100% 開源純 Python，直接從 GitHub 虛擬機連線至 Garmin 官方，絕不經過任何第三方中繼伺服器。

如果我今天休息沒有跑步，系統還會發送日報嗎？

會的！系統內建 36 小時判定機制。若最近沒有新運動，系統會自動轉發「今日休整與超補償日報」，統計您近 7 筆的累積跑量與負荷，由 AI 教練提供滾筒伸展、電解質修復處方與明日重啟課表預告，絕不重複發送舊活動，維持每日晨間儀式感。

我可以更改每日推播的時間嗎？

可以。只需編輯倉庫中的 .github/workflows/daily_task.yml 檔案，修改裡面的 cron: '0 22 * * *' 即可（注意 GitHub 採用 UTC 時間，台灣時間需減去 8 小時，例如台灣早上 06:00 對應 UTC 22:00）。
